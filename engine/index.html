The code that runs the gate

The actual logic behind the qualification gate and resume tailoring — real, working code against the schemas above, not a stub or a mockup. See Reports for a real run of this code against a test client and job posting.

qualification-gate.js

Complete — rubric v1.1

Scores a client against a job posting in two stages: 8 hard gates first (any failure rejects, no score computed), then a 100-point weighted score across 6 components if all gates pass. Bands: qualified / borderline / reject.
